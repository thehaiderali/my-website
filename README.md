# Portfolio Website

A modern, responsive portfolio website built with React, Tailwind CSS, and Framer Motion.

## Features

- 🌓 Dark/Light mode toggle with persistent preference
- 📱 Fully responsive design for mobile and desktop
- ✨ Smooth animations with blur reveal effects
- 🎨 Clean, minimalistic UI
- 🔧 Tools section with categorized skills
- 🔗 Social links (GitHub, Twitter, Email)

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- shadcn/ui (Button component)
- Lucide React (Icons)

## Installation

1. Clone the repository
```bash
git clone <your-repo-url>
cd portfolio
```

2. Install dependencies
```bash
npm install
```

3. Install additional packages
```bash
npm install lucide-react framer-motion
```

4. Start the development server
```bash
npm run dev
```


## Project Structure

```
src/
├── components/
│   └── Portfolio.jsx
├── App.jsx
└── main.jsx
```

## Customization

- Edit the `toolCategories` object to update skills
- Modify social links in the footer section
- Update personal information and bio text
- Adjust animation delays and durations in motion components
